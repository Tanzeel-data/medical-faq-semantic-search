# AI-Powered Medical FAQ Semantic Search

An NLP semantic search system that retrieves relevant medical question-answer pairs from the MedQuAD dataset using pretrained Sentence-BERT embeddings and FAISS.

## Project Overview

Traditional keyword-based search depends heavily on exact word overlap. This can cause problems when users express the same intent using different words.

This project addresses this limitation by converting medical questions into semantic embeddings using Sentence-BERT and retrieving relevant questions using FAISS and cosine similarity.

A TF-IDF keyword-search baseline is also implemented to compare traditional lexical retrieval with semantic search.

## Features

* Medical FAQ semantic search
* Sentence-BERT embeddings
* 384-dimensional embeddings
* FAISS vector similarity search
* Cosine similarity retrieval
* Top-k result retrieval
* TF-IDF keyword-search baseline
* Retrieval performance evaluation
* Interactive Gradio interface

## Dataset

The project uses the **MedQuAD Medical Question Answering Dataset**.

The dataset contains medical question-answer pairs covering a wide range of diseases, symptoms, diagnosis, and treatment-related topics.

After preprocessing:

* Original records: **16,412**
* Cleaned records: **16,359**
* Medical sources: **9**
* Unique medical focus areas: **5,125**

The dataset is downloaded automatically from Kaggle using KaggleHub.

## Model

**Sentence-BERT: `all-MiniLM-L6-v2`**

The pretrained model converts each medical question into a **384-dimensional embedding**.

The model was used without additional fine-tuning.

## Evaluation

The system was evaluated using **20 deliberately paraphrased medical queries**.

### Sentence-BERT + FAISS

| Metric         |      Score |
| -------------- | ---------: |
| Top-1 Accuracy | **90.00%** |
| Top-3 Accuracy | **95.00%** |
| Top-5 Accuracy | **95.00%** |
| MRR            | **0.9250** |

### TF-IDF Baseline

| Metric         |  Score |
| -------------- | -----: |
| Top-1 Accuracy | 50.00% |
| Top-3 Accuracy | 75.00% |
| Top-5 Accuracy | 80.00% |
| MRR            | 0.6017 |

The results show that Sentence-BERT semantic retrieval substantially outperformed traditional TF-IDF keyword retrieval on the paraphrased evaluation queries.

## Example

**User Query:**

> How can I tell if I have high blood pressure?

**Retrieved Question:**

> How to diagnose High Blood Pressure?

**Similarity:** 0.8876

Another example:

**User Query:**

> What are the signs of hypertension?

**Retrieved Question:**

> What are the symptoms of High Blood Pressure?

**Similarity:** 0.8379

These examples demonstrate the ability of semantic search to identify related concepts even when different terminology is used.

## Limitations

The evaluation uses a relatively small set of 20 manually created queries. The system also uses a general-purpose sentence embedding model rather than a medical-domain embedding model.

The retrieved answers come directly from the dataset and are not generated by an LLM.

## Future Improvements

Possible extensions include:

* Medical-domain embedding models

## Disclaimer

This project is developed for educational and research purposes. It is a semantic information-retrieval prototype and **should not be used for medical diagnosis, treatment decisions, or emergency medical advice**.
